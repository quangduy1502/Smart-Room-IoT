# Firmware Node B (Control & Web Node)
- **Thành viên phụ trách:** Thành viên A (Lập trình ESP32 & API), Thành viên B (Hỗ trợ HTML/JS)
- **Chức năng:** Nhận gói tin ESP-NOW, xuất JSON qua cổng USB Serial, phát Wi-Fi SoftAP và host Webserver nhúng (T07).
- **Môi trường:** PlatformIO / Arduino IDE (Board: YoloUNO ESP32-S3).
